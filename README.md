# Sonic Chaos (Master System) Disassembly
Disassembly for the SMS version of [Sonic Chaos/Sonic &amp; Tails](https://info.sonicretro.org/Sonic_Chaos). Yes, it's the 8-bit Sonic game that got excluded from the 3DS Virtual Console releases.

[Prototype](https://tcrf.net/Proto:Sonic_Chaos_(Sega_Master_System)/June_30,_1993) [versions](https://tcrf.net/Proto:Sonic_Chaos_(Sega_Master_System)/July_13,_1993) cannot be used with this disassembly.
